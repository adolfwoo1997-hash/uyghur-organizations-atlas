## 数据说明

- 名单来源：世界维吾尔代表大会（WUC）附属组织名录、各组织官网、美国非营利登记、公开报道，以及一份 28 条名录截图（OCR）。
- 坐标：OpenStreetMap / Photon 地理编码，街道级约 ±50–150 m；「城市级」仅城市中心。
- † 表示负责人取自 WUC 未标日期名录，可能已换届；△ 表示公开报道互相矛盾。
- 所有地址均为机构公开信息。
